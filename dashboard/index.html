Como ler este painel

S = score ponderado pela rubrica da tarefa (0 a 5). Cada célula é a média das entregas do modelo naquela categoria.

Aprov. % = parte das entregas liberadas para o cliente. pass@1 = aprovada já na primeira tentativa; pass@3 só existe com ao menos 3 entregas.

Min = mediana de minutos até a entrega ficar publicável. Custo/aprov. fica vazio quando falta custo em qualquer entrega aprovada do grupo.

Δ compara com a rodada anterior apenas tarefa+versão repetidas; a seta mostra direção, não significância.

Amostra pequena e parte subjetiva: não trate diferenças de poucos décimos como verdade.
