# Fase 2 — publicação (ESBOÇO, fora do escopo da v0.1)

Este repositório é **interno**. Nada do que existe aqui hoje (rodadas, scoreboards, guia, painel) está liberado para circulação externa.

Ideias registradas para uma fase futura, todas **dependentes de decisão do dono** antes de qualquer implementação:

1. **Qual conteúdo pode vazar**: agregados (scores por categoria, tips gerais) sem dados de clientes; nunca casos completos, KPIs ou entrevistas.
2. **Mudança de licença/visibilidade**: hoje tudo `internal`; uma fase pública exigiria reclassificar artefatos caso a caso e revisar o `guard`.
3. **Forma provável**: página estática com resultados agregados e aviso de amostra pequena, gerada a partir dos scoreboards — nunca expondo blind-map nem chaves de resposta.
4. **Pré-requisitos**: rodadas reais suficientes (n mínimo por categoria), revisão jurídica dos casos fictícios e validação do dono.

Nenhum pipeline desta fase existe ainda. Enquanto este arquivo não for substituído por um plano aprovado, **a resposta padrão é: sem publicação**.
